# Presentation kit

| File | Use |
|---|---|
| `FRIMS_jury_deck.html` | The deck. Open in any browser — fully self-contained (no internet needed). `→`/`←`/space to navigate, click right/left thirds of the screen, `Home`/`End`, `P` to print. `#7` in the URL jumps to slide 7. |
| `slides.md` | Same content in Marp Markdown — edit here, or render with the Marp VS Code extension / `marp slides.md --pdf`. |
| `DEMO_SCRIPT.md` | 3-minute live-demo walkthrough with talk track and what to do if something breaks. |
| `JURY_QA.md` | Our strengths/exposures, what moves the odds, and a question bank (data, method, validation, engineering, scale, impact) with prepared answers. |

## Export to PDF
Open `FRIMS_jury_deck.html` in Chrome → `P` (or ⌘P) → "Save as PDF", landscape, background graphics on.
Each slide prints on its own page.
